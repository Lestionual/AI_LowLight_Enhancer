AI Low-Light Enhancer

A deep learning-based low-light image and video enhancement system built using PyTorch and a U-Net architecture.

The project is designed to improve the visibility of images and live webcam feeds captured in low-light environments. The system automatically analyzes brightness and applies AI-based enhancement when the input falls below a specified brightness threshold.

Features
AI-based low-light image enhancement
Real-time webcam enhancement
Automatic brightness detection
Configurable low-light threshold
Original and enhanced video comparison
Desktop GUI built with PySide6
Virtual camera output support
U-Net deep learning architecture
GPU acceleration using CUDA when available
Training and validation pipeline
PSNR evaluation
SSIM evaluation
